## ZMF Java Launcher — preview

Unofficial, independent launcher for Minecraft: Java Edition on iPhone.
**Not affiliated with Mojang or Microsoft.**

### Install
* **AltStore / SideStore:** add the source URL
  `https://github.com/froelicherzachary80-collab/ZMF-JAVALAUNCHER-/releases/latest/download/altstore-source.json`
* **Signulous / other signers:** download the `.ipa` below and sign it.

### Works now
Version manager (install, verify, repair), Fabric profiles, mod manager and
Modrinth packs, server list with live status, ZMF Voice rooms (with a relay),
touch controls lab, Microsoft sign-in (once the app ID is approved by Microsoft).

### Not yet
Minecraft itself does not start yet: this build has no iOS Java runtime, iOS
LWJGL natives or desktop-GL layer, and needs JIT for usable speed. See
`docs/STATUS.md` for the full, honest list.

Checksums: `SHA256SUMS.txt`. Privacy: `PRIVACY.md`.
